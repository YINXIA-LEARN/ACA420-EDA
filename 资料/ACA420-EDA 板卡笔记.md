# 小梅哥 ACA420-EDA 板卡笔记

照片中的套件采用 ACA420-CORE 核心板和 ACA420-EDA 底板。中央金边小板承载安路 EG4S20BG256，外围的大板把 FPGA 引脚接到开关、显示、音频和扩展接口。按包装、实物布局、两份原理图及 TD 工程中的器件字段，可以对应到同一型号。本笔记依据资料和照片，尚未上电验证这块实物。

## 对照实物

| 照片位置 | 器件与用途 |
|---|---|
| 左上 USB 口 | USB 提供 5 V 电源。底板第 2 页显示，同一条 USB 数据线经过集线器，分别接板载 JTAG 下载器和 CH9102F 串口桥。前者用来配置 FPGA，后者供实验程序与电脑交换数据。 |
| 上沿两组四位显示器 | 合计八位七段数码管。第 11 章用段选决定显示的笔画、用位选轮流点亮八位。 |
| 上沿蓝色 VGA 接口、右侧蓝绿音频插座 | VGA 可输出彩条、图片和文字。ES8388 负责音频采集和播放，第 33 章演示音频回环。 |
| 下沿和右下 | 八个拨动开关 SW0～SW7、十四路底板用户灯 LED0～LED13、六个独立按键 S0～S5，另有一个标为 0～F 的 4×4 矩阵键盘。矩阵键盘通过四列扫描、四行读回识别十六个键。 |
| 核心板左侧纽扣电池 | 对应 GM1302 实时时钟的后备电源。 |
| 随盒遥控器 | 照片为 21 键红外遥控器。底板接收头 D22 的信号进入 T13。第 21 章按 NEC 协议解码，用 ChipWatcher 看地址和数据码。现成例程的顶层只接时钟、复位和红外输入，按遥控器时应在调试窗口看结果。 |

底板原理图还画出了 24LC64 EEPROM、DS18B20 温度传感器、无源蜂鸣器，以及模拟输入和输出。模拟输入 P2 对应 U3，图纸及引脚表写 **XL549**，教程及例程名用 **TLC549**。模拟输出 P3 对应 **DAC5311**。第 17 章的高速 DAC 实验另用外接 ACM9767 模块。摄像头 OV5640 和 4.3/5 寸 TFT 也属于扩展模块，三张照片能确认随盒有遥控器和跳线，其他模块是否随盒仍未知。

## 建立工程时

配套开发软件是安路 Tang Dynasty（TD），资料包提供 TD 5.6.5 安装包。例程的 `.al` 是 TD 工程，硬件选项为 **EG4 / EG4S20BG256**。Verilog 描述电路，`.adc` 把顶层端口绑定到 FPGA 封装管脚。教材用 ModelSim 做功能仿真，再在 TD 综合、布局布线、生成 `.bit`，通过板载 JTAG 下载。核心板还带 GD25Q16E 配置 Flash，用于掉电保存配置。教材第 34 章另列出了器件内嵌的 EM638325 SDRAM，组织为 2M × 32 位（8 MiB），摄像头工程用它缓存图像帧。

| 常用信号 | FPGA 管脚 | 核对结果 |
|---|---|---|
| 主时钟 CLK | K14 | 50 MHz，周期 20 ns。 |
| LED0、LED1 | R1、K3 | 底板第 4 页中用户灯的阴极经 1 kΩ 接地，所以 FPGA 输出高电平点亮。教材第 3 章表 3-1 写成低电平点亮，与底板图和第 10 章描述相反。 |
| 独立按键 S0、S5 | G1、P7 | 松开为高、按下为低。第 3 章计数器将 S0 用作复位，第 21 章红外实验用 S5；复位键取决于当前工程约束。 |
| UART_TX、UART_RX | E3、E4 | 方向以 FPGA 为准。第 8 章串口工程与引脚表一致。 |
| 红外 IR、蜂鸣器 BEEP | T13、B14 | 分别是接收输入和驱动输出。 |
| EEPROM 的 SCL、SDA | H1、F1 | ES8388 配置用另一对引脚 R5、M9。 |

引脚表还显示，VGA_DATA 和 TFT_rgb 共用同一组 16 根颜色数据线。合并显示例程时，只能在这些物理管脚上输出一组颜色数据。扩展 GPIO 编号、排针脚序与 FPGA 封装管脚是三套编号，外接模块时需对照底板第 7 页和引脚表。

## 从实验找资料

| 目标 | 教材章节和工程 |
|---|---|
| 看懂开关如何控制灯 | 第 2 章 `ch2_decoder3_8`，SW2、SW1、SW0 组成三位输入，选择 LED0～LED7 中的一盏。第 3 章 `ch3_bin_counter` 改用时钟计数，每 0.5 秒翻转 LED0。 |
| 串口、状态机和按键 | 第 4～8 章从收发单元讲到串口回环，第 9～11 章覆盖消抖、加减计数、数码管。 |
| 片上资源 | 第 12～16 章覆盖 PLL、ROM、RAM、双口 RAM 应用及 FIFO。 |
| 声音、键盘、遥控与模拟量 | 第 17～24 章，依次涉及高速 DAC 扩展、蜂鸣器、矩阵键盘、红外、板载 DAC/ADC 和数字电压表。红外解码工程为 `ch21_HT6221`，教材图 21-2 给出键码图。 |
| 显示、总线和图像系统 | 第 25～30 章讲 VGA/TFT 和图文显示，第 31～33 章讲 I²C、EEPROM 和音频，第 34～37 章讲 SDRAM、OV5640 及 VGA/TFT 显示链路。 |

主教材 V1.1 共 674 页。设计实例目录按 37 章打包，其中 `ch1.rar` 和 `ch35.rar` 只有目录，分别对应环境安装和摄像头理论。第 2 章是第一个带源码和引脚约束的上板工程。扩展资料中的 AC620、AC6102 等示例针对其他开发板，ACA420 的摄像头示例在第 36、37 章。
