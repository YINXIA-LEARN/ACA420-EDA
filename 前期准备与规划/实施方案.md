# 用 ACA420-EDA 测量悬臂梁多点位移与低频振动

**现场演示目标**：用一台固定相机同时看到梁底座的参考标记 R、梁中段 P1 和自由端 P2。手拨梁后，VGA 画面标出测点，串口同时记录各点位移。梁静止时轻微平移相机，对比校正前后的轨迹；遮住一个标记，屏上提示失锁，日志留下缺口。第三个运动点 P3 在前两点测准后加入。

**开工条件**：已知板卡为小梅哥 ACA420-EDA / EG4S20BG256。A 核对 OV5640 扩展模块、连接方向、VGA 显示器和线材是否到位；C 核对独立支架、夹具、稳定照明及可借量具。旧选题按 PH1P35 指定平台拟定，团队须向当届主办方确认可选赛题、替代板资格和截止日期，将公告或书面答复记入 Issue 后再确定报名方向。技术开发可以独立推进。

## 先搭一条能测的链路

| 环节 | 在这块板上如何实现 | 验证方式 |
|---|---|---|
| 采集和显示 | 以厂商第 36 章 `ch36_ov5640_sdram_vga.rar` 为起点。TD 打开包内 `ov5640_sdram_vga.al`，约束名为 `ov5640_sdram_hdmi_tft.adc`。顶层 `rtl/ov5640_sdram_vga.v` 接 8 位 DVP 数据、PCLK、HREF、VSYNC，默认图幅 1280×720。先复现原工程，再从 DVP_Capture 拼好的像素流分一路做测量。 | A 提供实拍画面、实际帧率、像素格式、帧起点/首个有效像素关系和时钟域。相机未到时先用第 25 章 VGA 彩条验证显示，用人工帧验证算法。 |
| 帧缓存和计算 | 沿用第 36 章 SDRAM 控制器。按 RGB565 计算，720p 每帧 1,843,200 字节，两帧约 3.52 MiB，在 8 MiB 容量内。每秒带宽另算：宽×高×2×（实测写帧率＋显示读帧率），再计刷新、换行及仲裁开销。测量走像素流，每个 ROI 只存像素数 N 与坐标和。 | 核查地址区间、FIFO 溢出/下溢和 TD 布局布线报告。容量预算不能替代带宽实测。帧末锁存和数值计算可共用一个除法器，保住像素通路吞吐。 |
| 位移与失锁 | 选高对比亮标记，先固定 ROI。中心为 (Σx/N, Σy/N)，以同一有效帧置零。竖向位移为 `[(yi−yi0)−(yR−yR0)] × mm_per_px`。参考点与目标同平面；一个 R 只校正共同平移。面积越界、触边、遮挡均标无效；R 失效时该帧所有校正量无效。 | B/C 用同一图像核对阈值、ROI 边界和整数累加，再比较定点质心。首帧、空 ROI、遮挡恢复、复位和最大累加值均留测试向量。 |
| 同步输出 | 像素域产生 frame_id 和帧快照，用异步 FIFO 或握手跨到 50 MHz 系统域；VGA 按帧号关联图像与结果。S 键置零、拨码切原图/阈值图。串口只送摘要，PC 作图和存档。 | 每条记录可追溯到 frame_id、采样时间、目标、坐标、面积、valid、拒测原因、原始与校正位移。先试 115200/8N1，总量低于约 11.5 kB/s；逐帧测包长，超出时打包整数并报告丢包。 |

## 值得投入的展示功能

1. **同一录制，两项对照。** 在量具读数稳定时轻移相机，同时显示原始和校正位移，比较同一时间窗的残余峰峰值。随后遮挡 P2 再遮挡 R，展示局部失效与全局校正失效的区别。这两项只需复用已有坐标和有效位，能直接回答“测量结果何时可信”。
2. **改变梁长再测一次。** 核心测量通过后，用板上按键触发两次等长记录，比较两种夹持长度的自由衰减轨迹、各点峰峰值和主频。先在 PC 用帧时间戳分析有效连续片段，帧率与采样窗足够后再尝试 FPGA 零交叉估频。用独立视频或参考传感器核对频率，峰值比只作同工况比较。
3. **借助现有板载器件降低复演成本。** 前两项稳定后，用 24LC64 存标定系数和工位配置，带版本、校验和恢复默认值；数码管显示所选测点，LED 提示失锁。测试断电重启及损坏配置回退。换镜头、物距或分辨率时重新标定。TFT、激励电机、自焊副板和 FFT 等扩展按赛题要求和余量决定。

## 三人交付与验收

按 15 个有效开发日安排；每个关口由主责成员提交证据，另一人独立复现。当前可复用资产是[合成模型和单 ROI 实验](多点位移原型/README.md)，真实视频链、整机时序和精度仍待验证。

| 时间 | 主责与交接 | 完成标志 |
|---|---|---|
| D1–2 | A 列明硬件、TD 版本和例程；B 复跑单 ROI 仿真；C 复跑合成样例，搭参考点、量具与梁。 | 建立物料/赛题 Issue；B、C 约定阈值相等时的行为、坐标原点、置零及日志字段。 |
| D3–6 | A 复现相机到 VGA，把一帧样本和时序交 B/C。B 并行做 R＋2 点，C 准备同平面毫米标尺。 | 保存稳定视频、帧率与异常计数；首末像素不丢。缺相机可交仿真和彩条，真机验收顺延。 |
| D7–9 | B 接测量链和 UART；A 做显示叠加与时序检查；C 用真实样帧对照模型。 | 同帧 R＋2 点位移能回读。遮挡和恢复有记录，参考失效时所有校正曲线断开。 |
| D10–12 | C 用百分表或卡尺施加至少五档已知位移，每档往返、重复至少五次；A/B 复核对齐与日志。 | 提交原始读数、标定系数、残差、最大绝对误差、重复性和拒测率；提供校正前后的同窗对照。 |
| D13–15 | 三人演示自由衰减，比较至少三种工况、各重复三次；A 封存稳定工程，B/C 交叉复演。 | 提交帧率/漏帧、连续运行时长、资源与时序报告、配置文件哈希、复演步骤和短视频。记录无效工况，精度与频段以实测为准。 |

若时序或日程吃紧，先停板上频率估计与配置存储，再缩减到两个运动点。保留同帧参考、有效位、标定和日志。每个实验在 PR 里注明提交号、板型、相机模式、照明与量具、有效样本数及证据位置，让另一位成员能照着复做。
